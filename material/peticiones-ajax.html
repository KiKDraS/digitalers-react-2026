Clase de React: Peticiones AJAX 🚀

Cómo hablar con servidores usando GET, POST, PUT y DELETE.

¿Qué es AJAX y una API? (La Analogía del Restaurante 🍽️)

Imagina que tu aplicación de React es un cliente en un restaurante.

  • Cocina = Servidor (o Base de Datos)
  • Menú = Documentación de la API
  • Mesero = API (AJAX / Fetch), el intermediario que lleva tus pedidos

AJAX es pedir datos al servidor sin recargar toda la página.

Los 4 Verbos Principales (CRUD)

📖 GET (Read)

Pedir y recibir datos. Ej: cargar lista de productos.

✍️ POST (Create)

Enviar datos nuevos. Ej: formulario de registro.

🔄 PUT (Update)

Modificar algo existente. Ej: editar perfil.

🗑️ DELETE (Delete)

Eliminar un dato. Ej: borrar un comentario.

Herramientas de React para AJAX

  1. Fetch API: función del navegador para hacer peticiones.
  2. useState: guarda los datos recibidos.
  3. useEffect: ejecuta la petición al cargar el componente.

Nuestro Servidor de Pruebas: MockAPI.io 🧪

Usaremos MockAPI, un servicio gratuito que permite crear, leer, actualizar y borrar datos reales.

¿Por qué no JSONPlaceholder? Porque es de solo lectura: acepta POST o DELETE pero no guarda cambios. MockAPI sí los guarda.

Configuración rápida:

  1. Regístrate en mockapi.io (puedes usar GitHub).
  2. Crea un proyecto y un recurso llamado posts.
  3. Define dos campos: title (string) y body (string).
  4. Copia la URL generada, similar a: https://TU_ID.mockapi.io/posts

Esa URL será nuestra API_URL.

Ejemplo Práctico: Un Blog Conectado a MockAPI

Vamos a construir un componente PostManager paso a paso.

Usaremos async/await dentro de try...catch para manejar errores de forma clara.

Paso 1: Componente de carga (Spinner)


function Spinner() {
  return (
    <div className="d-flex justify-content-center p-4">
      <div className="spinner-border" role="status">
        <span className="visually-hidden">Cargando...</span>
      </div>
    </div>
  );
}

Paso 2: Estado inicial y función GET


import { useState, useEffect } from 'react';

const API_URL = 'https://TU_ID.mockapi.io/posts';

function PostManager() {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  // GET: cargar posts al montar
  useEffect(() => {
    const fetchPosts = async () => {
      try {
        setLoading(true);
        const response = await fetch(API_URL);
        if (!response.ok) throw new Error('Error al cargar posts');
        const data = await response.json();
        setPosts(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    fetchPosts();
  }, []);

  if (loading) return <Spinner />;
  if (error) return <div className="alert alert-danger">{error}</div>;
  // ... resto del componente
}

Paso 3: Crear un post (POST)


  const [newPostTitle, setNewPostTitle] = useState('');

  const handleCreatePost = async (e) => {
    e.preventDefault();
    setLoading(true);
    try {
      const newPost = {
        title: newPostTitle,
        body: 'Cuerpo del post'
      };

      const response = await fetch(API_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(newPost)
      });

      if (!response.ok) throw new Error('No se pudo crear el post');
      const createdPost = await response.json();
      setPosts([...posts, createdPost]); // añade al final
      setNewPostTitle('');
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

Paso 4: Actualizar un post (PUT)


  const handleUpdatePost = async (id) => {
    setLoading(true);
    try {
      const postToUpdate = posts.find(p => p.id === id);
      const updatedData = { title: `(Actualizado) ${postToUpdate.title}` };

      const response = await fetch(`${API_URL}/${id}`, {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(updatedData)
      });

      if (!response.ok) throw new Error('No se pudo actualizar');
      const updatedPost = await response.json();
      setPosts(posts.map(p => p.id === id ? updatedPost : p));
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

Paso 5: Eliminar un post (DELETE)


  const handleDeletePost = async (id) => {
    setLoading(true);
    try {
      const response = await fetch(`${API_URL}/${id}`, {
        method: 'DELETE'
      });

      if (!response.ok) throw new Error('No se pudo eliminar');
      setPosts(posts.filter(p => p.id !== id));
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

Paso 6: Interfaz completa


  return (
    <div>
      <h3>Crear Nuevo Post</h3>
      <form onSubmit={handleCreatePost} className="mb-4">
        <div className="input-group">
          <input
            type="text"
            className="form-control"
            value={newPostTitle}
            onChange={(e) => setNewPostTitle(e.target.value)}
            placeholder="Título del nuevo post"
            required
          />
          <button type="submit" className="btn btn-primary">Crear (POST)</button>
        </div>
      </form>

      <h3>Lista de Posts (GET)</h3>
      {loading && <Spinner />}

      <ul className="list-group">
        {posts.map(post => (
          <li key={post.id} className="list-group-item d-flex justify-content-between align-items-center">
            {post.id} - {post.title}
            <div>
              <button
                onClick={() => handleUpdatePost(post.id)}
                className="btn btn-warning btn-sm me-2"
              >
                Actualizar (PUT)
              </button>
              <button
                onClick={() => handleDeletePost(post.id)}
                className="btn btn-danger btn-sm"
              >
                Eliminar (DELETE)
              </button>
            </div>
          </li>
        ))}
      </ul>
    </div>
  );
}

Con estos pasos ya tienes un CRUD completo conectado a un servidor real. Recuerda reemplazar TU_ID por tu ID de MockAPI.
