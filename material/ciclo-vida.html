Ciclo de Vida del Componente

Cómo manejar el ciclo de vida en componentes funcionales usando useEffect, useRef y useLayoutEffect. Sin clases, solo funciones.

📖 Introducción

En React, el ciclo de vida se refiere a las distintas etapas por las que pasa un componente desde que se crea hasta que se destruye. En los componentes funcionales, estas etapas se gestionan mediante hooks, principalmente useEffect.

A diferencia de enfoques anteriores basados en clases, los hooks nos permiten sincronizar efectos con el renderizado de una manera declarativa y limpia. Cada vez que un componente funcional se renderiza, React ejecuta la función del componente; los hooks nos permiten "engancharnos" a ese proceso.

💡 Idea clave: En componentes funcionales, el ciclo de vida se gestiona a través de efectos que se sincronizan con el renderizado.

Con useEffect podemos ejecutar código después del render, limpiar recursos antes de desmontar o realizar acciones cuando cambian ciertos valores. Además, useRef y useLayoutEffect cubren necesidades específicas dentro de ese ciclo.

🔄 Fases del Ciclo de Vida

Todo componente funcional pasa por tres fases principales:

🌱

Montaje

El componente se inserta en el DOM por primera vez.

🔄

Actualización

El componente se re-renderiza porque cambió su estado o sus props.

🗑️

Desmontaje

El componente se elimina del DOM.

En componentes funcionales no hay métodos separados para cada fase, sino que usamos useEffect (y useLayoutEffect) para ejecutar código en momentos específicos.

⚛️ Hooks Clave para el Ciclo de Vida

Estos son los hooks más importantes para manejar el ciclo de vida en componentes funcionales:

useState

Maneja el estado local. Cada cambio de estado provoca una nueva renderización (fase de actualización).

useEffect

El hook principal para efectos secundarios. Se ejecuta después del render y puede cubrir montaje, actualización y desmontaje.

useLayoutEffect

Similar a useEffect, pero se ejecuta sincrónicamente después de las mutaciones del DOM y antes de que el navegador pinte. Ideal para mediciones y ajustes que no deben causar parpadeos.

useRef

Mantiene una referencia mutable que persiste durante toda la vida del componente sin causar re-render. Útil para acceder al DOM, guardar timers, contadores o valores previos.

🎯 useEffect en Detalle

useEffect es la herramienta principal para sincronizar el ciclo de vida en componentes funcionales. Su firma es: 

useEffect(() => {
  // Código del efecto (se ejecuta después del render)
  return () => {
    // Función de limpieza (opcional)
  };
}, [dependencias]);

Controlar cuándo se ejecuta

  • Sin array de dependencias: el efecto se ejecuta después de cada render (montaje y todas las actualizaciones).
  • Con array vacío []: el efecto se ejecuta solo una vez después del montaje.
  • Con dependencias [dep1, dep2]: el efecto se ejecuta en el montaje y cada vez que alguna de las dependencias cambia.

Función de limpieza

Si el efecto devuelve una función, React la ejecutará:

  • Antes de desmontar el componente.
  • Antes de la siguiente ejecución del efecto (cuando las dependencias cambian).

Esto es esencial para limpiar suscripciones, timers, event listeners, etc.

💻 Ejemplos de Código

1. Efecto en montaje

import React, { useEffect } from 'react';

function MiComponente() {
  useEffect(() => {
    console.log('Componente montado');
    // Aquí puedes hacer llamadas a APIs, suscripciones, etc.
  }, []); // Array vacío: solo se ejecuta una vez

  return <div>Hola Mundo</div>;
}

2. Efecto con dependencias (actualización)

import React, { useState, useEffect } from 'react';

function Contador() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log(`El contador cambió a: ${count}`);
    document.title = `Contador: ${count}`;
  }, [count]); // Se ejecuta cuando 'count' cambia

  return (
    <button onClick={() => setCount(count + 1)}>
      Incrementar ({count})
    </button>
  );
}

3. Efecto con limpieza (desmontaje)

import React, { useEffect } from 'react';

function Temporizador() {
  useEffect(() => {
    const intervalId = setInterval(() => {
      console.log('Tick');
    }, 1000);

    // Función de limpieza
    return () => {
      clearInterval(intervalId);
      console.log('Limpieza: intervalo detenido');
    };
  }, []); // Solo montaje y desmontaje

  return <div>Temporizador activo</div>;
}

4. Suscripción a eventos del teclado

import React, { useState, useEffect } from 'react';

function KeyLogger() {
  const [lastKey, setLastKey] = useState('');

  useEffect(() => {
    const handleKeyPress = (event) => {
      setLastKey(event.key);
      console.log(`Tecla presionada: ${event.key}`);
    };

    window.addEventListener('keydown', handleKeyPress);

    // Limpieza al desmontar o antes de volver a ejecutar
    return () => {
      window.removeEventListener('keydown', handleKeyPress);
      console.log('Limpieza: listener eliminado');
    };
  }, []); // Solo se registra una vez

  return <div>Última tecla: {lastKey || 'Ninguna'}</div>;
}

5. useRef para controlar un elemento de video

Un caso típico es acceder a un elemento del DOM para ejecutar métodos imperativos, como reproducir o pausar un video. 

import React, { useRef } from 'react';

function VideoPlayer() {
  const videoRef = useRef(null);

  const handlePlay = () => {
    videoRef.current.play();
  };

  const handlePause = () => {
    videoRef.current.pause();
  };

  return (
    <div>
      <video
        ref={videoRef}
        src="https://www.w3schools.com/html/mov_bbb.mp4"
        width="320"
        height="240"
        controls
      />
      <div>
        <button onClick={handlePlay}>Reproducir</button>
        <button onClick={handlePause}>Pausar</button>
      </div>
    </div>
  );
}

6. useRef para contar renders sin causar bucles

useRef mantiene su valor entre renders sin provocar nuevas renderizaciones. Ideal para métricas o depuración. 

import React, { useState, useRef } from 'react';

function RenderCounter() {
  const [count, setCount] = useState(0);
  const renderCount = useRef(0);

  // Incrementamos la referencia en cada render
  renderCount.current += 1;

  return (
    <div>
      <p>Valor del estado: {count}</p>
      <p>Número de renders: {renderCount.current}</p>
      <button onClick={() => setCount(count + 1)}>
        Incrementar
      </button>
    </div>
  );
}

7. useLayoutEffect para mantener la posición del scroll

Al añadir elementos a una lista (por ejemplo, en un chat o feed), queremos evitar que el scroll salte bruscamente. Con useLayoutEffect podemos ajustar el scroll antes de que el navegador pinte. 

import React, { useState, useLayoutEffect, useRef } from 'react';

function ChatFeed() {
  const [messages, setMessages] = useState([]);
  const listRef = useRef(null);

  useLayoutEffect(() => {
    if (listRef.current) {
      const list = listRef.current;
      // Mantener el scroll al final si ya estaba cerca del final
      const isNearBottom =
        list.scrollHeight - list.scrollTop - list.clientHeight < 100;

      if (isNearBottom) {
        list.scrollTop = list.scrollHeight;
      }
    }
  }, [messages]); // Se ejecuta justo después de cada cambio en 'messages'

  const addMessage = () => {
    setMessages(prev => [...prev, `Mensaje ${prev.length + 1}`]);
  };

  return (
    <div>
      <div
        ref={listRef}
        style={{
          height: '200px',
          overflowY: 'auto',
          border: '1px solid #ccc',
          padding: '10px',
        }}
      >
        {messages.map((msg, index) => (
          <div key={index}>{msg}</div>
        ))}
      </div>
      <button onClick={addMessage}>Añadir mensaje</button>
    </div>
  );
}

En este ejemplo, useLayoutEffect se ejecuta después de que React haya actualizado el DOM, pero antes de que el navegador lo pinte. Así podemos calcular si el usuario estaba cerca del final de la lista y, si es así, desplazar el scroll hasta el nuevo final sin parpadeos visibles.

✅ Conclusión

Los componentes funcionales con hooks ofrecen una manera elegante y declarativa de manejar el ciclo de vida en React. useEffect es la pieza central que nos permite ejecutar código en el montaje, actualización y desmontaje, todo dentro de una única API unificada.

Con useRef podemos mantener referencias estables y con useLayoutEffect realizar ajustes precisos antes de que el navegador pinte. Al entender cómo funcionan las dependencias y la función de limpieza, puedes crear componentes robustos, eficientes y fáciles de mantener.

🚀 Recuerda: En el mundo de los hooks, piensa en términos de sincronización de efectos, no de métodos separados.
