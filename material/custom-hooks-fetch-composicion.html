React: Custom Hooks, Composición y AJAX 🚀

Custom Hooks: Creando Lógica Reutilizable

Un custom hook es una función JavaScript que utiliza hooks de React internamente y que podemos reutilizar en distintos componentes. Nos permite extraer lógica con estado para no repetir código.

Ejemplo: useLocalStorage

Hook que sincroniza un estado con localStorage.


import { useState, useEffect } from 'react';

// Hook personalizado
function useLocalStorage(key, initialValue) {
  // Estado inicial: lee de localStorage si existe
  const [storedValue, setStoredValue] = useState(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch (error) {
      return initialValue;
    }
  });

  // Efecto: guarda en localStorage cada vez que cambia el estado
  useEffect(() => {
    window.localStorage.setItem(key, JSON.stringify(storedValue));
  }, [key, storedValue]);

  // Retorna el estado y la función para actualizarlo
  return [storedValue, setStoredValue];
}

// Uso en un componente
function App() {
  const [nombre, setNombre] = useLocalStorage('nombre', 'Invitado');
  return (
    <input
      value={nombre}
      onChange={e => setNombre(e.target.value)}
    />
  );
}

Composición: Construyendo UIs como Legos 🧩

La composición consiste en crear componentes pequeños y reutilizables que se combinan para formar interfaces más complejas.

Ejemplo básico: Tarjeta de Alerta


// Componente genérico
function Card({ children }) {
  return <div className="card shadow-sm">{children}</div>;
}

// Componente específico que usa Card
function AlertCard() {
  return (
    <Card>
      <div className="card-body">
        <h3 className="card-title text-danger">⚠️ ¡Acción Requerida!</h3>
        <p className="card-text">Debes actualizar tu información de perfil.</p>
      </div>
    </Card>
  );
}

La prop children permite inyectar contenido dentro del componente.

Formularios con Composición 📝

Vamos a separar la lógica del formulario (hook), los campos de entrada (componente Input) y el contenedor (componente Form).

Paso 1: Hook useForm


import { useState } from 'react';

// Hook para manejar el estado de un formulario
function useForm(initialState = {}) {
  const [formData, setFormData] = useState(initialState);

  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData(prev => ({ ...prev, [name]: value }));
  };

  return { formData, handleChange };
}

Paso 2: Componente Input


// Componente de input reutilizable con etiqueta
function Input({ label, name, ...rest }) {
  return (
    <div className="mb-3">
      <label htmlFor={name} className="form-label">{label}</label>
      <input id={name} name={name} className="form-control" {...rest} />
    </div>
  );
}

Paso 3: Componente Form


// Contenedor de formulario con título y manejo de envío
function Form({ title, onSubmit, children }) {
  return (
    <div className="card shadow-sm">
      <div className="card-body p-4">
        <h2 className="card-title text-center mb-4">{title}</h2>
        <form onSubmit={onSubmit}>
          {children}
        </form>
      </div>
    </div>
  );
}

Paso 4: Componer todo en LoginForm


function LoginForm() {
  const { formData, handleChange } = useForm({ email: '', password: '' });

  const handleSubmit = (e) => {
    e.preventDefault();
    alert(`Iniciando sesión con: ${formData.email}`);
  };

  return (
    <Form title="Iniciar Sesión" onSubmit={handleSubmit}>
      <Input
        label="Correo Electrónico"
        type="email"
        name="email"
        value={formData.email}
        onChange={handleChange}
      />
      <Input
        label="Contraseña"
        type="password"
        name="password"
        value={formData.password}
        onChange={handleChange}
      />
      <button type="submit" className="btn btn-primary w-100 mt-3">
        Ingresar
      </button>
    </Form>
  );
}

Con esta estructura cada pieza es reutilizable en otros formularios.

Peticiones AJAX y Manejo de Estados Asíncronos 🌐

Veremos dos formas de manejar la carga de datos desde una API.

Enfoque 1 (Clásico): useEffect + useState

Usamos estados separados para datos, carga y error.


import { useState, useEffect } from 'react';

// Componente de carga reutilizable
function Spinner() {
  return (
    <div className="d-flex justify-content-center p-4">
      <div className="spinner-border" role="status">
        <span className="visually-hidden">Cargando...</span>
      </div>
    </div>
  );
}

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    // Reiniciamos estados al cambiar userId
    setLoading(true);
    setError(null);
    setUser(null);

    const fetchUser = async () => {
      try {
        const response = await fetch(`https://jsonplaceholder.typicode.com/users/${userId}`);
        if (!response.ok) throw new Error('No se pudo obtener el usuario.');
        const data = await response.json();
        setUser(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    fetchUser();
  }, [userId]);

  if (loading) return <Spinner />;
  if (error) return <div className="alert alert-danger">Error: {error}</div>;

  return (
    <div className="card shadow-sm">
      <div className="card-body">
        <h2 className="card-title">{user.name}</h2>
        <p className="card-text">Email: {user.email}</p>
      </div>
    </div>
  );
}

Enfoque 2: Suspense para Code-Splitting (React 18 y anterior)

<Suspense> se usaba principalmente para carga diferida de componentes con React.lazy(). Para capturar errores necesitamos un Error Boundary (único caso donde se usa una clase).

1. Error Boundary reutilizable (clase)


import React from 'react';

class ErrorBoundary extends React.Component {
  state = { hasError: false };

  static getDerivedStateFromError(error) {
    return { hasError: true };
  }

  componentDidCatch(error, errorInfo) {
    console.error("Error atrapado:", error, errorInfo);
  }

  render() {
    if (this.state.hasError) {
      return this.props.fallback;
    }
    return this.props.children;
  }
}

Los Error Boundaries solo pueden ser componentes de clase porque usan métodos de ciclo de vida específicos.

2. Uso de React.lazy y Suspense


import React, { Suspense, lazy } from 'react';
import ErrorBoundary from './ErrorBoundary';

function Spinner() {
  return <div className="text-center p-4">Cargando componente...</div>;
}

const UserProfileDetails = lazy(() => import('./UserProfileDetails'));

function UserProfileLazy() {
  return (
    <div className="card">
      <div className="card-header">
        <h3>Perfil de Usuario (Lazy Loaded)</h3>
      </div>
      <div className="card-body">
        <ErrorBoundary fallback={<div className="alert alert-danger">No se pudo cargar el componente.</div>}>
          <Suspense fallback={<Spinner />}>
            <UserProfileDetails userId={1} />
          </Suspense>
        </ErrorBoundary>
      </div>
    </div>
  );
}
